# Portfolio Web

A simple static portfolio website showcasing projects, skills, and contact information.

## Purpose

This repository contains a lightweight personal portfolio built with HTML, CSS, and JavaScript. It's intended as a starting point for customization and deployment as a personal website.

## Features

- Responsive layout (desktop and mobile friendly)
- Static content: projects, about, contact
- Easy to customize styles and scripts

## Quick Start

1. Open the project folder in your code editor.
2. Open `index.html` in your browser to view the site.

Optional: serve with a local dev server for live reload. For example, in VS Code install the Live Server extension and choose "Open with Live Server".

## Development

- Main files:
  - `index.html` — site markup
  - `Style.css` — site styles
  - `Script.js` — interactive behavior
- Assets are stored under the `assets/` directory (fonts, images, pdf).

## File Structure

```
index.html
README.md
Style.css
Script.js
assets/
  fonts/
  images/
  pdf/
```

## Deployment

Since this is static, you can deploy to GitHub Pages, Netlify, Vercel, or any static-hosting provider. Simply push the repository and follow the provider's instructions.
